# Titanic Data Analysis

## Project Overview

This project analyses the Titanic passenger dataset to understand the factors associated with passenger survival.

The analysis focuses on variables such as gender, passenger class, age, family relationships, fare and embarkation location. Tableau was used to create visualizations and an interactive dashboard to present the findings.

## Dataset

The dataset contains information about 891 Titanic passengers.

Some of the main variables used in the analysis include:

- Passenger Class
- Gender
- Age
- SibSp (siblings/spouses)
- Parch (parents/children)
- Fare
- Embarked
- Survived

The `Survived` column was used as the main outcome:
- `1` = Survived
- `0` = Did Not Survive

## Analysis Performed

The project includes analysis of:

- Overall passenger survival
- Survival by gender
- Survival by passenger class
- Survival by age group
- Survival by SibSp
- Survival by Parch
- Survival by fare
- Survival by embarkation location
- Missing values

## Key Findings

- The overall observed survival rate was approximately **38.4%**.
- Female passengers had a much higher observed survival rate than male passengers.
- First-class passengers had a higher observed survival rate than second- and third-class passengers.
- Passengers under 18 had a higher observed survival rate than passengers aged 18 and above among passengers with recorded ages.
- Passengers travelling with siblings/spouses or parents/children generally had higher observed survival rates.
- Passengers paying higher fares had a higher observed survival rate.
- Survival rates also differed according to embarkation location.

## Conclusion

The analysis shows that survival was not evenly distributed among Titanic passengers. Gender and passenger class showed particularly noticeable differences in survival rates, while age, family-related variables, fare and embarkation location also showed differences between passenger groups.

The results represent associations found in the dataset and do not prove that any single factor directly caused survival or death.
